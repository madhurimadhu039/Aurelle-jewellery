# Aurelle Jewellery – Antigravity Brief

Contents:
- `PROMPT.md` – the full project prompt (paste into Antigravity, or point it at this file)
- `reference/Aurelle_Jewellery_Luxury_UI_Moodboard.png` – visual moodboard referenced by the prompt

How to use:
1. Open Antigravity and create a new workspace/project.
2. Copy this whole folder into the workspace (so the moodboard is available to the agent).
3. Tell the agent: "Read PROMPT.md and the moodboard in reference/, then build the complete project as described."
4. Add your own Firebase config and metal-rate API key to `.env` afterwards (see `.env.example` the agent generates).
